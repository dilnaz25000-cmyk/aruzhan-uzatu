# Аружан — Қыз Ұзату Тойы (Шақыру Билеті)

Бұл жоба Аружанның қыз ұзату тойына арналған электронды шақыру билеті (веб-сайт). 
Сайт толықтай мобильді құрылғыларға бейімделген (Mobile-first) және заманауи дизайнмен жасалған.

## Мүмкіндіктері (Features)
- **Музыка**: Димаш Құдайбергеннің «Қарлығашым ұя салғанда» әні ойнайды (0:08 секундтан бастап).
- **Динамикалық эффектілер**: Scroll жасағанда анимациямен ашылатын блоктар.
- **Интерактивті карта**: 2GIS сілтемесі арқылы мейрамхана бағытын ашу.
- **Кері санақ (Countdown)**: Тойға дейін қалған уақытты (күн, сағат, минут) көрсетеді.
- **WhatsApp RSVP**: Қонақтар «Келемін» немесе «Келе алмаймын» батырмаларын басып, тікелей WhatsApp арқылы жауап бере алады.

## GitHub Pages арқылы сайтты интернетке шығару нұсқаулығы

Сайтты интернетке (тегін) шығару үшін келесі қадамдарды орындаңыз:

1. **GitHub аккаунт ашу**: Егер аккаунтыңыз жоқ болса, [github.com](https://github.com/) сайтына кіріп тіркеліңіз.
2. **Жаңа репозиторий құру**: 
   - Жоғарғы оң жақтағы **+** батырмасын басып, **New repository** таңдаңыз.
   - Репозиторий атын жазыңыз (мысалы, `aruzhan-wedding`).
   - Көріну деңгейін **Public** етіп қалдырыңыз.
   - **Create repository** басыңыз.
3. **Файлдарды жүктеу**:
   - Пайда болған бетте **uploading an existing file** деген сілтемені басыңыз.
   - Осы папкадағы барлық файлдарды (`index.html`, `style.css`, `script.js`, суреттер мен музыка) сол жерге сүйреп әкеліп тастаңыз.
   - Файлдар жүктелген соң, төмендегі **Commit changes** батырмасын басыңыз.
4. **GitHub Pages қосу**:
   - Репозиторийдің **Settings** (Параметрлер) бөліміне кіріңіз.
   - Сол жақ мәзірден **Pages** дегенді таңдаңыз.
   - **Branch** бөлімінде `None` орнына `main` (немесе `master`) тармағын таңдап, **Save** басыңыз.
5. **Дайын!** 
   - 1-2 минуттан кейін жоғарыда сіздің сайтыңыздың сілтемесі пайда болады (мысалы: `https://sizdin-atynyz.github.io/aruzhan-wedding/`). 
   - Осы сілтемені барлық қонақтарға жібере аласыз!
